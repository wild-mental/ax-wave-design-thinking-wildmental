# 워크시트 원본

「서비스 아이디어 기획을 위한 데이터 기반 디자인 씽킹」 교재의 워크시트 문서입니다. 이틀 동안 산출물 16개의 템플릿 표는 모두 `worksheet.md` 한 파일에 씁니다. 이 폴더의 파일을 직접 고치지 말고, 내 비공개 저장소와 내 컴퓨터의 작업 폴더로 옮겨 씁니다. 명령어는 쓰지 않고 GitHub 웹 화면에서만 작업합니다.

## 시작하기

1. 오른쪽 위 **+ → New repository**에서 저장소 이름을 `design-thinking-worksheet`로 쓰고, 공개 범위는 반드시 **Private**(비공개)를 고른 뒤 만듭니다.
2. 이 폴더의 [`worksheet.md`](worksheet.md)를 열고 **Copy raw file**(복사 아이콘)로 내용 전체를 복사합니다.
3. 내 저장소에서 **Add file → Create new file**(빈 저장소라면 **creating a new file**)을 누르고, 파일 이름 `worksheet.md`로 붙여 넣은 뒤 **Commit changes**를 누릅니다.
4. 내 저장소의 **Settings → Collaborators → Add people**에서 강사 GitHub 아이디 `wild-mental`을 초대합니다.
5. 내 컴퓨터에 같은 이름의 폴더 `design-thinking-worksheet/`를 만들고, 내 저장소의 `worksheet.md` 화면에서 **Download raw file**(내려받기 아이콘)로 이 폴더에 저장합니다.

클릭 순서는 교재 1.1절 · 부록 A-1과 온라인 가이드 「작업 폴더와 워크시트 저장소 준비 가이드」를 봅니다.

## 내 저장소에 생기는 파일

| 파일 · 폴더 | 쓰임 |
|---|---|
| `worksheet.md` | 산출물 16개의 템플릿 표. 맨 위의 사용법부터 읽습니다. 수업 중에는 작업 폴더의 `worksheet.md`를 채웁니다 |
| `research/` | 리서치 보고서와 출처 메모 (`status-report.md` 등 6개) |
| `prototype/` | 개념 프로토타입 `concept-prototype.html` |
| `interviews/` | 페르소나 카드, 인터뷰 계획서 · 기록 · 결과 보고서 |

하루를 마치기 전에 작업 폴더 안의 `worksheet.md`와 세 폴더를 **Add file → Upload files**로 저장소에 올립니다(교재 부록 A-1).

## 꼭 지킬 것

- 내 워크시트 저장소는 끝까지 **Private**으로 두고, 강사 `wild-mental`만 초대합니다.
- 개념 프로토타입은 배포하지 않습니다. 인터뷰 때 내 노트북에서 열어 보여 줍니다.
- 실제 사람의 이름 · 연락처 같은 개인정보를 넣지 않습니다. 페르소나는 모두 가상 인물이고, AI 가상 인터뷰 결과에는 가상이라는 표시를 남깁니다(교재 부록 A-4).
