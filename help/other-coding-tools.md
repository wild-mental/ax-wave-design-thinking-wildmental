# 다른 AI 코딩 도구로 할 때 (OpenAI Codex · Cursor)

> **준비 중인 도움말입니다.** 수업 전에 채워집니다. 그동안은 지시문 킷 「쓰는 법」 6번을 보세요.

Claude Code를 쓸 수 없거나 사용 한도를 다 써서 한동안 쓸 수 없으면, 다른 회사의 AI 코딩 도구로 같은 작업 폴더를 열고 이어서 작업해도 됩니다. 이 페이지는 Claude Code에서 하던 조작이 다른 도구에서는 무엇인지 한 표로 보여 줍니다. 그 도구의 계정과 요금은 각 회사 안내를 따릅니다.

## 그대로인 것과 도구에 맞출 것

| 그대로인 것 | 도구에 맞출 것 |
|---|---|
| 작업 폴더 `design-thinking-worksheet/`와 그 안의 폴더 · 파일 이름 | 폴더를 여는 메뉴 |
| [지시문 킷](../kits/claude-code-research-prompts.md)의 지시문 내용 | 파일을 가리키는 방법. `@research/status-report.md`처럼 `@`를 쓰는 도구가 많지만, 안 되면 그 도구의 파일 첨부 방법을 쓰거나 "research 폴더의 status-report.md 파일"처럼 경로를 말로 씁니다 |
| 결과를 파일로 저장하고, 출처를 직접 열어 확인하는 순서 | 허락을 묻는 방식과 버튼 이름 |

바꾼 뒤에는 "이 폴더에 무엇이 있는지 알려 줘"로 같은 폴더가 열렸는지 먼저 확인합니다. 다시 Claude Code로 돌아와도 파일은 작업 폴더에 그대로 이어집니다.
