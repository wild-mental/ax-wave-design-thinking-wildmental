# 다른 AI 코딩 도구로 할 때 (OpenAI Codex · Cursor)

교재: 지시문 킷 「쓰는 법」 6번 · 쓰는 때: Claude Code를 쓸 수 없거나 사용 한도를 다 써서 한동안 쓸 수 없을 때

## 이 페이지에서 볼 것

Claude 계정에는 일정 시간 동안 쓸 수 있는 양(사용 한도)이 있습니다. 실습 중에 한도를 다 써서 Claude Code를 한동안 쓸 수 없으면, 다른 회사의 AI 코딩 도구로 같은 작업 폴더를 열고 이어서 작업해도 됩니다. 이 페이지는 Claude Code에서 하던 조작이 OpenAI Codex와 Cursor에서는 무엇인지 한 표로 보여 줍니다. 두 도구의 계정과 요금은 각 회사 안내를 따르고, 설치는 각 회사 누리집의 내려받기 안내를 봅니다.

| 그대로인 것 | 도구에 맞출 것 |
|---|---|
| 작업 폴더 `design-thinking-worksheet/`와 그 안의 폴더 · 파일 이름 | 폴더를 여는 메뉴 |
| [지시문 킷](../kits/claude-code-research-prompts.md)의 지시문 내용. 고치지 않고 그대로 씁니다 | 파일을 가리키는 방법(`@` 표기) |
| 결과를 파일로 저장하고, 출처 링크를 직접 열어 확인하는 순서 | 웹 검색을 쓰는 방법, 허락을 묻는 방식과 버튼 이름 |
| 워크시트 `worksheet.md`의 칸과 완료 기준 체크리스트 | 되돌리는 버튼 |

## 어느 화면을 쓰나

- **OpenAI Codex**: **ChatGPT 데스크톱 앱**(macOS · Windows) 안에서 씁니다. chatgpt.com/download에서 앱을 받아 로그인하고, 새 대화에서 **Codex**를 고릅니다. 터미널판(CLI)도 있지만 이 수업에서는 터미널이 필요 없는 데스크톱 앱을 씁니다.
- **Cursor**: Cursor 자체가 데스크톱 앱(macOS · Windows)입니다. cursor.com에서 받아 설치하고 로그인합니다. 대화로 일을 시키는 곳은 **Agent**(에이전트: 파일을 읽고 고치는 AI 작업 창)입니다.

## 조작 대응표

| 하는 일 | Claude Code (Code 탭) | OpenAI Codex (ChatGPT 데스크톱 앱) | Cursor |
|---|---|---|---|
| 작업 폴더 열기 | 입력창 아래 **환경 선택**에서 Local, **폴더 선택**에서 `design-thinking-worksheet` | Codex를 고른 뒤 폴더 열기(또는 프로젝트를 만들고 폴더 추가)로 `design-thinking-worksheet`를 고릅니다 | 앱을 열고 폴더를 고릅니다. 편집기 화면에서는 **File → Open Folder**. 그다음 `Cmd+I`(Windows `Ctrl+I`)로 Agent를 엽니다 |
| 파일을 가리키기 (`@`) | `@research/status-report.md`처럼 `@`를 치고 후보에서 고릅니다 | 입력창에 `@`를 쳐서 파일 후보가 뜨면 고릅니다. 안 뜨면 "research 폴더의 status-report.md 파일"처럼 경로를 글로 씁니다 | `@`를 치면 파일 · 폴더 후보가 뜹니다. `@research/status-report.md`처럼 Claude Code와 같게 씁니다 |
| 웹 검색으로 출처 찾기 | 지시문대로 보내고, 웹 검색이나 웹 페이지 읽기를 허락할지 물으면 허락합니다 | 지시문 끝에 "웹에서 찾아 주장마다 출처 링크를 붙여 줘"를 더합니다. 인터넷 사용 허락을 물으면 허락합니다 | Codex와 같게 지시문 끝에 한 줄을 더합니다. 검색하겠다고 허락을 물으면 허락합니다 |
| 파일 고치기 전 허락 | 모드 선택에서 고치기 전에 묻는 모드를 씁니다 | 입력창 아래 권한 선택에서 **Ask for approval**을 고릅니다. **Full access**는 고르지 않습니다 | 파일 편집은 바로 적용되고 바뀐 부분 보기로 확인합니다. 먼저 계획만 받으려면 입력창에서 `Shift+Tab`으로 **Plan Mode**를 켭니다. 명령 실행 허락에서 **Run Everything**은 고르지 않습니다 |
| 만든 HTML을 브라우저로 열어 보기 | 파일 탐색기(Finder)에서 `prototype/concept-prototype.html`을 더블클릭, 고친 뒤에는 강력 새로 고침(Mac `Cmd+Shift+R` · Windows `Ctrl+Shift+R`) | 같습니다 | 같습니다 |
| 되돌리기 | 큰 변경 전 복사본 `<원래 파일 이름>-before-<다음 작업>`을 만들고, 망가지면 "복사본과 똑같은 내용으로 되돌려 줘" | Claude Code와 같은 복사본 방법을 씁니다 | 복사본 방법이 기본입니다. 대화 기록의 **Restore Checkpoint**(에이전트가 고치기 전 상태로 파일을 되돌림)도 쓸 수 있습니다 |
| 사용 한도 확인 | 입력창 아래 줄의 사용량 표시 | 앱의 설정이나 계정 화면에서 봅니다. 위치는 앱 버전마다 다릅니다 | Cursor 설정이나 cursor.com 계정 화면의 사용량에서 봅니다 |

**허락 방식이 다를 때.** Codex와 Cursor는 작업 폴더 안의 파일을 하나하나 묻지 않고 고칠 수 있습니다. 먼저 보고 싶으면 지시문 끝에 "무엇을 바꿀지 목록으로 먼저 보여 주고, 내가 승인하면 고쳐 줘."를 붙입니다. 어느 도구든 작업 폴더 밖 수정이나 설치 명령은 거절합니다.

## 리서치에서 달라지는 점

이 수업의 리서치 지시문(현황 분석 · 이해관계자 · 광범위 탐색 · 정량 검증)은 웹 검색이 되어야 제대로 돌아갑니다.

1. **검색했는지 먼저 확인합니다.** 결과에 출처 링크가 하나도 없거나 "제가 알고 있는 바로는"처럼 기억에 기대는 말이 보이면 웹 검색을 쓰지 않은 것입니다. "방금 결과는 웹에서 찾은 것인가? 아니면 웹에서 다시 찾아 출처 링크를 붙여 줘."라고 보냅니다.
2. **출처 확인 규칙은 같습니다.** 어느 도구든 링크를 직접 열어 같은 내용 · 같은 숫자가 있는지 봅니다. 열리지 않는 링크는 지우거나 "확인 필요"로 표시합니다(킷 「함께 지키는 작업 규칙」 2번).
3. **웹 검색이 안 되는 도구라면** 웹 대화형 AI(ChatGPT · Gemini 같은 웹 화면의 심층 리서치 기능)에 같은 지시문을 넣고, 결과를 지시문이 정한 파일(예: `research/status-report.md`)에 붙여 넣어 저장합니다. 그다음 코딩 도구에서는 그 파일을 `@`로 가리켜 정리만 맡깁니다. 이때도 내 리서치와 관계없는 예시 글은 넣지 않습니다(킷 「함께 지키는 작업 규칙」 6번).

## 바꾸는 순서

1. 지금 고치던 파일이 있으면 복사본을 만듭니다. 예) `research/segment-map.md` → `research/segment-map-before-<다음 작업>.md`
2. Claude Code의 대화를 끝내고, 새 도구에서 같은 작업 폴더를 엽니다.
3. "이 폴더에 무엇이 있는지 알려 줘"로 같은 폴더가 열렸는지 확인합니다.
4. 새 도구에 지금 단계를 알려 줍니다. 킷 「새 대화 첫머리 블록」을 붙이고, 지금까지 만든 파일(`@worksheet.md`, `@research/…`)을 가리켜 "먼저 읽고 이해한 내용을 다섯 줄로 요약해 줘. 파일은 아직 고치지 마."라고 보냅니다.
5. 요약이 맞으면 하던 단계의 지시문부터 이어서 보냅니다.

## 바꿔 쓸 때 주의

- **새 도구는 앞 대화를 모릅니다.** 대화를 통째로 옮기지 말고, 정리된 파일만 가리킵니다(킷 「함께 지키는 작업 규칙」 5번).
- **같은 파일을 두 도구로 동시에 고치지 않습니다.** 한쪽 변경이 사라질 수 있습니다. 한 번에 한 도구만 씁니다.
- **파일 이름 규칙은 같습니다.** 도구가 다른 이름(예: `report.md`, `-backup`, 날짜 붙이기)으로 저장하면 지시문이 정한 이름으로 바꾸게 합니다.
- **한도가 풀리면 돌아와도 됩니다.** 파일은 작업 폴더에 그대로 있습니다. Claude Code로 돌아올 때도 새 대화로 시작하고 4번처럼 파일을 다시 읽힙니다.

## 막혔을 때

- **새 도구가 파일을 못 찾는다** → 작업 폴더를 한 단계 위나 아래로 연 것입니다. `design-thinking-worksheet` 맨 위 폴더를 다시 엽니다.
- **Codex에서 권한 선택이 안 보이거나 Ask for approval이 없다** → 앱을 최신 버전으로 올리고 다시 엽니다. 그래도 없으면 지시문 끝에 "내가 승인하기 전에는 고치지 마."를 붙여 씁니다.
- **결과에 출처 링크가 없다** → 위 「리서치에서 달라지는 점」 1번처럼 웹에서 다시 찾게 합니다. 그래도 안 되면 3번의 방법으로 이어 갑니다.
- **Cursor가 한 번에 여러 파일을 고쳤다** → 대화 기록에서 Restore Checkpoint로 되돌리거나 복사본으로 되돌린 뒤, 고칠 파일 하나만 가리켜 다시 지시합니다.
- **도구가 터미널 명령을 실행하겠다고 한다** → 이 수업에는 필요 없습니다. 거절하고 "명령은 실행하지 말고, 작업 폴더의 파일만 읽고 고쳐 줘."라고 보냅니다.

Claude Code의 작업 폴더 조작은 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」, 리서치 한 사이클은 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」를 봅니다.
