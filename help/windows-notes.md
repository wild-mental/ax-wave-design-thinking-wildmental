# Windows 사용자 메모

> **준비 중인 도움말입니다.** 수업 전에 채워집니다. 그동안은 아래 단축키 표를 보세요.

교재와 가이드는 Mac 키를 먼저 적은 곳이 많습니다. Windows 노트북을 쓰는 분은 이틀 동안 만나는 차이를 이 한 쪽에서 찾으세요. Mac의 `Cmd`는 Windows의 `Ctrl`로 바꿔 누르면 대부분 맞습니다.

## 1. 단축키 대응표

| 하는 일 | Mac | Windows | 쓰는 곳 |
|---|---|---|---|
| 복사 · 붙여 넣기 | `Cmd+C` · `Cmd+V` | `Ctrl+C` · `Ctrl+V` | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 |
| 찾기 | `Cmd+F` | `Ctrl+F` | 「[AI 가상 인터뷰 가이드](../guides/ai-virtual-interview-guide.md)」 |
| 강력 새로 고침 | `Cmd+Shift+R` | `Ctrl+Shift+R` | 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 (교재 부록 A-3) |

> [작성 예정] 가이드를 다 쓴 뒤 가이드에 나온 단축키만 더함(새 폴더 · 이름 바꾸기 · 화면 확대 등)

## 2. 파일과 폴더
