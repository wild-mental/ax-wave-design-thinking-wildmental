# Windows 사용자 메모

교재와 가이드는 Mac 키를 먼저 적은 곳이 많습니다. Windows 노트북을 쓰는 분은 이틀 동안 만나는 차이를 이 한 쪽에서 찾으세요. 각 항목의 「쓰는 곳」이 그 조작을 실제로 쓰는 가이드입니다.

기준은 Windows 11 한국어판입니다. 메뉴 이름이 화면과 조금 다르면 괄호 안의 다른 이름도 찾아보세요.

## 1. 단축키 대응표

Mac의 `Cmd`는 Windows의 `Ctrl`로 바꿔 누르면 대부분 맞습니다. 그렇지 않은 키도 있으니 아래 표를 보세요.

| 하는 일 | Mac | Windows | 쓰는 곳 |
|---|---|---|---|
| 복사 · 붙여 넣기 | `Cmd+C` · `Cmd+V` | `Ctrl+C` · `Ctrl+V` | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 |
| 모두 고르기 | `Cmd+A` | `Ctrl+A` | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 |
| 찾기 | `Cmd+F` | `Ctrl+F` | 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」, 「[TAM·SAM·SOM과 세그먼트 맵 가이드](../guides/tam-sam-som-segment-map-guide.md)」, 「[AI 가상 인터뷰 가이드](../guides/ai-virtual-interview-guide.md)」 |
| 브라우저에 열린 글을 파일로 저장 | `Cmd+S` | `Ctrl+S` | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 |
| 여러 파일 · 폴더 함께 고르기 | `Cmd`를 누른 채 클릭 | `Ctrl`을 누른 채 클릭 | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 |
| 새 폴더 | `Cmd+Shift+N` (Finder) | `Ctrl+Shift+N` (파일 탐색기) | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 |
| 파일 · 폴더 이름 바꾸기 | 고르고 `Return` | 고르고 `F2` | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 |
| 파일 복제 | `Cmd+D` (Finder) | `Ctrl+C` → `Ctrl+V` (2절 「복제한 뒤 이름 고치기」) | 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 |
| 늘 여는 앱 바꾸기 | `Cmd+I` (정보 가져오기) → 다음으로 열기 → 「모두 변경」 | 단축키 없음. 오른쪽 클릭 → **연결 프로그램 → 다른 앱 선택** → 「항상」 (2절) | 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 |
| 강력 새로 고침 | `Cmd+Shift+R` | `Ctrl+Shift+R` | 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」, 「[갤러리 워크 발표 가이드](../guides/gallery-walk-guide.md)」 |
| 화면 확대 (브라우저) | `Cmd` + `+` | `Ctrl` + `+` | 「[갤러리 워크 발표 가이드](../guides/gallery-walk-guide.md)」 |
| 창을 화면 반쪽에 붙이기 | 창 왼쪽 위 초록색 버튼에 포인터 → 왼쪽 · 오른쪽 배치 | `Win+←` · `Win+→` | 「[갤러리 워크 발표 가이드](../guides/gallery-walk-guide.md)」 |
| 입력창에서 보내지 않고 줄 바꾸기 | `Shift+Enter` | `Shift+Enter` | 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」 |

- Mac 키보드의 `Return`은 Windows의 `Enter`와 같은 키입니다.
- `Ctrl+Shift+N`은 파일 탐색기에서는 새 폴더지만, 브라우저(Chrome · Edge)에서는 시크릿 창을 엽니다. 새 폴더를 만들 때는 파일 탐색기 창을 먼저 한 번 누르고 씁니다.

## 2. 파일과 폴더

### 이름이 다른 것

| Mac | Windows | 쓰는 곳 |
|---|---|---|
| Finder | 파일 탐색기 | 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 |
| 텍스트 편집기 | 메모장 | 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」, 「[AI 가상 인터뷰 가이드](../guides/ai-virtual-interview-guide.md)」, 「[갤러리 워크 발표 가이드](../guides/gallery-walk-guide.md)」 |
| 다음으로 열기 | 연결 프로그램 | 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 |

### 확장자 보이기

Windows는 처음에 `.md`, `.html` 같은 확장자(파일 이름 끝의 형식 표시)를 숨깁니다. 첫날 작업 폴더를 만들기 전에 한 번 켜 두세요.

1. 파일 탐색기를 엽니다.
2. 위쪽 **보기 → 표시 → 파일 이름 확장명**을 눌러 체크합니다. 화면에 따라 "파일 확장명"으로 보일 수 있습니다.

켜 두지 않으면 `worksheet.md.txt`나 `DESIGN.md.txt`처럼 확장자가 잘못 붙은 것을 알아채기 어렵습니다. 쓰는 곳: 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 3번, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 0번(준비물)

### 내려받은 `worksheet.md`를 작업 폴더로 옮기기

GitHub에서 **Download raw file**로 받은 파일은 보통 **다운로드** 폴더에 저장됩니다.

1. 파일 탐색기 왼쪽 목록에서 **다운로드**를 엽니다. 방금 받은 `worksheet.md`가 맨 위(「오늘」 묶음)에 있습니다.
2. 파일을 고르고 `Ctrl+X`(잘라내기)를 누릅니다.
3. 왼쪽 목록에서 바탕 화면(또는 문서)을 열고 `design-thinking-worksheet` 폴더를 두 번 눌러 들어간 뒤, 빈 곳을 한 번 누르고 `Ctrl+V`를 누릅니다.
4. 이름이 정확히 `worksheet.md`인지 봅니다. 같은 파일을 여러 번 받아 `worksheet (1).md`가 되었으면 `F2`로 이름을 고칩니다.

브라우저에 글 화면만 열려 `Ctrl+S`로 저장했다면, 저장 창에서 위치를 바로 `design-thinking-worksheet` 폴더로 고르고 파일 이름을 `worksheet.md`로 씁니다. 파일 형식을 고를 수 있으면 **모든 파일**을 고르고, 저장한 뒤 이름 끝에 `.txt`가 붙지 않았는지 봅니다. 쓰는 곳: 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 3번과 「막혔을 때」

### 복제한 뒤 이름 고치기

큰 변경 전에 남기는 복사본은 `<원래 파일 이름>-before-<다음 작업>` 형식으로 이름을 붙입니다. `<다음 작업>`은 영문 소문자와 하이픈으로 짧게 씁니다. Windows에는 Mac의 `Cmd+D` 같은 복제 키가 없어서 복사와 붙여 넣기를 씁니다.

1. 파일 탐색기에서 파일을 고르고 `Ctrl+C`, `Ctrl+V`를 누릅니다.
2. 같은 폴더에 `- 복사본`이 붙은 파일이 생깁니다. 예) `concept-prototype - 복사본.html`
3. 그 파일을 고르고 `F2`를 누릅니다. 확장자를 보이게 켜 두었다면 `.html` 앞부분만 선택됩니다.
4. 이름을 `concept-prototype-before-second-screen.html`처럼 고칩니다. 띄어쓰기와 `복사본`이 남지 않았는지 봅니다.

복사본은 원래 파일과 같은 폴더(예: `prototype/`, `research/`)에 둡니다. Claude Code에 "○○ 파일을 ○○-before-○○ 이름으로 복사해 둬. 복사본은 고치지 마."라고 시켜도 됩니다. 다른 폴더에 붙여 넣을 때는 `- 복사본`이 붙지 않으므로, 나만의 DESIGN.md 사본은 붙여 넣은 뒤 `F2`로 이름만 `DESIGN.md`로 바꿉니다. 쓰는 곳: 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」 「되돌리기: 큰 변경 전에 복사본 남기기」, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 0번(준비물) · 「큰 변경 전에 복사본 만들기」

### 경로 표기

가이드와 지시문 킷은 경로를 `research/status-report.md`처럼 `/`로 씁니다. Windows 파일 탐색기 주소 표시줄에서는 같은 경로가 `\`로 나뉘어 보입니다.

| 가이드에 적힌 경로 | Windows 파일 탐색기에서 보이는 모습 (바탕 화면에 만든 경우) |
|---|---|
| `design-thinking-worksheet/research/` | `C:\Users\<사용자 이름>\Desktop\design-thinking-worksheet\research` |
| `prototype/concept-prototype.html` | `…\design-thinking-worksheet\prototype\concept-prototype.html` |

- 한국어 키보드와 일부 글꼴에서는 `\`가 `₩`로 보입니다. 같은 글자입니다.
- Claude Code에 경로를 쓸 때는 가이드처럼 `/`로 씁니다. `@research/status-report.md`처럼 작업 폴더 안의 경로만 씁니다.
- Claude Code에 "전체 경로로 알려 줘"라고 물으면 `C:\Users\…`처럼 `\`가 섞인 답이 올 수 있습니다. 끝부분이 `design-thinking-worksheet\research`처럼 작업 폴더 바로 아래면 맞습니다.
- 브라우저로 연 파일의 주소창에는 다시 `/`로 보입니다. 끝부분이 `prototype/concept-prototype.html`인지 봅니다.

쓰는 곳: 「[작업 폴더와 워크시트 저장소 준비 가이드](../guides/workspace-repo-setup-guide.md)」 4번, 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」 2번, 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 「막혔을 때」

### `.html`은 브라우저로, `.md`는 메모장으로 열기

1. 파일 탐색기에서 `prototype/concept-prototype.html`을 두 번 누릅니다. Chrome이나 Edge가 열리면 됩니다.
2. 브라우저가 아니라 메모장이나 다른 앱이 열리면, 파일을 오른쪽 클릭하고 **연결 프로그램**에서 Chrome이나 Edge를 고릅니다.
3. 늘 브라우저로 열리게 하려면 **연결 프로그램 → 다른 앱 선택**에서 브라우저를 고르고 「항상」을 누릅니다.
4. 파일을 고친 뒤에는 브라우저에서 강력 새로 고침(`Ctrl+Shift+R`)을 해야 바뀐 화면이 보입니다.

`research/status-report.md`나 `interviews/interview-report.md` 같은 `.md` 파일은 오른쪽 클릭 → **연결 프로그램 → 메모장**으로 엽니다. 메모장에서도 `Ctrl+F`로 찾을 수 있습니다. 쓰는 곳: 「[개념 프로토타입 만들기 가이드](../guides/concept-prototype-guide.md)」 2번 · 「막혔을 때」, 「[Claude Code 리서치 에이전트 사용 가이드](../guides/claude-code-research-agent-guide.md)」 4번, 「[AI 가상 인터뷰 가이드](../guides/ai-virtual-interview-guide.md)」 「끝 표시가 빠진 인용 찾기」, 「[갤러리 워크 발표 가이드](../guides/gallery-walk-guide.md)」
