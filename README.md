# 서비스 아이디어 기획을 위한 데이터 기반 디자인 씽킹 · 온라인 자료실

교재 「서비스 아이디어 기획을 위한 데이터 기반 디자인 씽킹」(2026년 11월 30일~12월 1일)과 함께 쓰는 온라인 자료실입니다. 이 첫 화면이 **교재와 자료실을 잇는 표**입니다.

- 교재에서 `→ 온라인 가이드: 「이름」` 표시를 봤다면, 아래 표에서 같은 **절**이나 **쪽**을 찾으세요. 가이드 이름은 교재와 글자 하나까지 같습니다.
- 「함께 쓰는 자료」 열은 그 절에서 같이 여는 것입니다.
  - **워크시트:** 내 작업 폴더의 `worksheet.md`에서 그 이름의 칸을 엽니다.
  - **킷:** 지시문 킷에서 그 이름의 지시문을 복사합니다.
  - **전문:** 중심 예제 리서치 보고서 전문에서 그 절의 원문을 봅니다.
- 도구 화면은 자주 바뀝니다. 교재의 부록 A로 흐름을 잡고, 실제 버튼 위치는 여기서 확인하세요.
- 실습 중에 막히면 [막혔을 때 모음](help/stuck-guide.md)부터 보세요.

## 처음 오셨다면

1. 이 자료실 주소 `https://wild-mental.github.io/ax-wave-design-thinking-wildmental/`를 즐겨찾기에 넣습니다.
2. GitHub에서 **비공개(Private)** 저장소 `design-thinking-worksheet`를 새로 만듭니다.
3. 자료실 원본(이 자료실의 GitHub 화면)에서 워크시트 원본 [worksheet.md][ws]를 열고 **Copy raw file**로 전체를 복사해, 내 저장소에 같은 이름 `worksheet.md`로 붙여 넣습니다.
4. 내 저장소의 **Settings → Collaborators → Add people**에서 강사 GitHub 아이디 `wild-mental`을 초대합니다.
5. 내 컴퓨터에 같은 이름의 작업 폴더 `design-thinking-worksheet/`를 만들어 `worksheet.md`를 넣고, Claude Code 데스크톱 앱에서 그 폴더를 엽니다.

단계별 순서와 막혔을 때 할 일은 「[작업 폴더와 워크시트 저장소 준비 가이드](guides/workspace-repo-setup-guide.md)」에 있습니다(교재 1.1절 · 부록 A-1).

## 지켜 주세요

- 워크시트 저장소 `design-thinking-worksheet`는 끝까지 **Private**으로 두고 강사 GitHub 아이디 `wild-mental`만 초대합니다.
- 개념 프로토타입은 배포하지 않습니다. 인터뷰 때 내 노트북에서 열어 보여 줍니다.
- 실제 사람의 이름·연락처 같은 개인정보를 리서치와 인터뷰 기록에 넣지 않습니다. 페르소나는 모두 가상 인물입니다.
- 인터뷰에서 옮긴 말 끝에는 `(짝 롤플레잉)` · `(AI 가상 인터뷰)` · `(실제 인터뷰)` 가운데 하나를 붙입니다(교재 부록 A-4).
- 교재와 이 자료실의 중심 예제 인물(김예비 · 박사장 등)은 모두 수업을 위해 만든 **가상 인물**이고, 인터뷰 결과 예시는 실제 고객의 말이 아닙니다.
